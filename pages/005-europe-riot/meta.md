# 页面 005：隔岸观火

- 页号：005
- 类型：分镜页（5 格纵向）
- 场景：夜，欧洲老城石板街；十九世纪立面的窗洞黑洞洞的，街心倒翻的马车与木箱燃成街垒，浓烟卷上屋脊；低空不断有烟花炸开，人群的剪影在火光里涌动
- 时间地点：民国二十七年冬 / 欧洲 · 一座老城街区（画面无字，靠石板路、老式街灯、欧式立面交代）
- 出场角色：001（暴乱者为无名群像，不入角色库）
- 动作/分镜：
  - P1 大全景：街口望去，远处街垒燃烧、烟柱翻卷，屋顶上空烟花炸开；人群剪影朝火处涌，和尚只是近景角落一个不动的小身影
  - P2 中景：他站在街沿，双手垂在身侧空空，袖口纹丝不动；火星从他肩边斜掠而过，身后是虚化奔涌的人群；他目光平静地跟着人群
  - P3 大格（主格）：低角仰拍暴乱者群像——压低的帽檐与围巾遮住脸，高举火把、酒瓶与断木板，街垒上的马车与木箱烧得通红；一枚照明烟花在半空炸开，把街道劈成极端的黑白
  - P4 特写：他的脸，四分之三侧，眼皮半垂、神色不动；火光只舔亮一侧脸颊，眉心朱砂是全图唯一的红；画面边缘垂着一截佛珠，背景火焰虚成一片
  - P5 远景（俯角）：从屋顶俯看整条街——烟柱、散开的人群、仍在燃的街垒；他一人逆着人流走开，背影很小，越走越远
- 叙事节点：004 之后他进入人间的另一端——不再是战场，而是人群自己烧起来的地方。他不劝、不拦、不出手，只是看着：立住他「旁观者」的一面，也埋下「他为何不再出手」的疑问
