# 页面 006：满街颜色

- 页号：006
- 类型：分镜页（5 格纵向，本页破例上色）
- 场景：夜，纽约曼哈顿的街道峡谷；摩天楼、铁艺消防梯、路边的黄色出租车与冒汽的井盖，霓虹与橱窗把湿沥青照出反光；一支游行队伍沿街涌过，彩带、气球、纸屑与羽毛漫天
- 时间地点：民国二十八年夏 / 美国 · 纽约（画面无字，靠楼群、消防梯、出租车、街灯交代）
- 出场角色：001（游行者为无名群像，不入角色库）
- 动作/分镜：
  - P1 大全景（高角）：楼群夹出的峡谷里，一条彩虹色的洪流沿街推进，纸屑像雪一样落，霓虹在湿沥青上碎成片；和尚站在人行道边一小段台阶上，灰袍与满街彩色像两块互不相干的布
  - P2 中景：队伍从他面前涌过——面具、羽毛、亮片、彩带、气球，男装女装混作一片，谁也辨不出来；他双手空空垂在身侧，只把头侧过去看
  - P3 大格（主格）：低角仰拍群舞——身体被拉长，手臂交错成网，头饰与羽毛向上飞散，速度线与纸屑糊满整格；一道彩虹色带横贯黑白线稿
  - P4 特写：他的脸，四分之三侧；彩色纸屑落在肩头和眉上，背景的彩色虚成一片光斑；眉心朱砂与整街的颜色对峙
  - P5 远景（平视）：队伍远去，街上只剩纸屑和瘪掉的气球；他仍站在原处，随后转身要走，背影在霓虹下拖得很长
- 叙事节点：从战场的血、草原的兽，到人群自己的狂欢——第三次旁观。这一页他不劝、不拦、不评判，只看；「群魔乱舞」只表现为失序的狂欢，不把任何人画成妖魔

- 表现尺度：群像一律面具或剪影，不给可辨认面部；**不画恶魔、角、獠牙等妖魔化符号**；舞者可上身彩绘但不得画性器官、不得有性暗示；不出现文字、标语、旗帜图案（彩带与气球只做纯色条纹）
