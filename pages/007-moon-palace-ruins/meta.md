# 页面 007：广寒残宫

- 页号：007
- 类型：分镜页（5 格纵向）
- 场景：月面。灰白的月壤一直铺到环形山的边缘，天是纯黑的，星子极密，地球悬在半空像一枚发亮的圆盘；远处一片半塌的宫阙——飞檐折断、殿柱倾倒，碎片散落在没有风的静里
- 时间地点：民国二十九年 / 月面 · 广寒宫遗址（画面无字，靠月壤、环形山、地球、宫阙形制交代）
- 出场角色：001（无其他人物）
- 动作/分镜：
  - P1 大全景（高角）：环形山围出的荒原，地球悬在天上，远处宫阙的轮廓塌了一半；和尚是一枚很小的黑点，沿着一道旧车辙似的裂痕走向废墟
  - P2 中景：他在半塌的宫门前停步；门楣上的匾额碎裂、只剩无字的凹槽，两侧石阶断成几截，瓦当散在脚边
  - P3 大格（主格）：广寒宫残骸——倾颓的殿柱斜插进月壤，翻倒的琉璃瓦铺了一地，一面裂成数瓣的铜镜半埋其中，一尊半埋的石像面部已经崩落；一棵石化的桂树立在废墟中央，枝干如骨
  - P4 特写：他低下头，一片碎瓦落进他空着的掌心；腕上佛珠垂着，指缝干净；背景是残殿和地球投来的冷光
  - P5 远景：他坐在断裂的石阶上，背对废墟，面向地平线上的地球；袈裟铺开，身形很小，环形山的轮廓像一圈围墙把他围在中间
- 叙事节点：006 的满街颜色之后，他走到一个彻底没有人的地方——连神话都塌了。这里没有妖、没有敌人、没有可渡的人，只有废墟；立住他「走到尽头」的孤绝，为后续的转折留白
